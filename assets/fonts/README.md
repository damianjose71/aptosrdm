# Tipografía corporativa

`roboto-condensed-latin.woff2` es el archivo variable de **Roboto Condensed**
(peso 400–700, subconjunto latino) que utiliza todo el sitio.

- Fuente: [Google Fonts · Roboto Condensed](https://fonts.google.com/specimen/Roboto+Condensed)
- Licencia: Apache License 2.0 (ver `LICENSE.txt`).

El archivo se sirve localmente para que la tipografía no dependa de una CDN
externa y se mantenga consistente en todas las páginas.
